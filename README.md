# simple-social-cli

**Archived 2026-10-07.** Moved to [ssterminal](https://github.com/DavidFruin/ssterminal), full history included. The CLI, the interactive wizard and the TUI now live in that one repo.

To update an existing install:

```
git clone https://github.com/DavidFruin/ssterminal.git
cd ssterminal && make && sudo make install
```

The binaries and PATH names (`sscli`, `sswiz`, `sstui`) are unchanged, so your config and login sessions keep working.
